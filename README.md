## Descripción

La Plataforma Académica Básica es un sitio web sencillo que simula la página de inicio de una plataforma académica. Su finalidad no es ser una aplicación completa, sino demostrar el flujo de trabajo colaborativo con Git y GitHub: repositorio, ramas, commits, pull request, revisión de código y fusión con la rama principal.

## Estructura del proyecto

- `README.md`: descripción del proyecto e integrantes.
- `index.html`: estructura HTML inicial de la página.
- `style.css`: estilos básicos del proyecto.

## Flujo de trabajo

1. Se trabaja en la rama `feature/estructura-inicial`, creada a partir de `main`.
2. Los cambios se registran en commits descriptivos.
3. Se abre un pull request hacia `main`, que es revisado por un compañero.
4. Una vez aprobado, el pull request se fusiona con `main`.
